# MKChat
Formerly available @ https://mkchat.net, https://mkchat.app

- MK Chat was created by [themkdev](https://github.com/themkdev) and later rewritten in entirety by me ([Nick Phillips](https://github.com/8h9x)).
- As of Version 0.0.1-next, the project has transitioned from the Apache 2.0 license to the BSD 4-Clause license. Previous versions persist their previous licensing terms (or lack thereof).
- Formal hosting/deployment support is not guaranteed. Feel free to submit patches via prs and submit issues; however, do not expect quick responses as this project is largely unmaintained.

External Dependencies
- [@std/msgpack](https://jsr.io/@std/msgpack) - Encoding and decoding for the msgpack format (from the deno std lib).
